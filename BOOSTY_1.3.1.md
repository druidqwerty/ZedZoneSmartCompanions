## Smart Companions 1.3.1

Manage your squad without punching holes in your base.

- Fixed the blank companion cards, chest list and settings in F8.
- Fixed missing Russian and Chinese text; replaced unsupported emoji labels with readable text.
- Clicking the mod's windows and buttons no longer passes the same click to world controls.
- Existing companion settings and saves are preserved. No restart is needed to switch languages or settings; close the game once to install the updated DLL.

Requires ZED ZONE Code Mod Loader: subscribe and run its `install.cmd` once.

## Умные напарники 1.3.1

Управляйте отрядом, не разнося собственную базу ударами.

- Исправлены пустые карточки напарников, список ящиков и настройки в F8.
- Исправлены квадраты вместо русского и китайского текста; неподдерживаемые эмодзи заменены читаемыми надписями.
- Клики по окнам и кнопкам мода больше не передаются игровому управлению.
- Сохранения и настройки напарников сохраняются. Язык и настройки меняются без перезапуска; для установки обновлённой DLL один раз закройте игру.

Нужен ZED ZONE Code Mod Loader: подпишитесь и один раз запустите его `install.cmd`.
