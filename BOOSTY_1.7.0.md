## Smart Companions 1.7.0 — True Physical Looting & Chest Carrying

Version **1.7.0** removes all remaining instant item teleports so companions physically walk to every item, corpse, and chest on foot:

- **Physical Ground, Corpse & Wild Chest Scavenging:** when ordered to sweep loot (or auto-looting nearby), companions build a route queue, walk to each ground item, corpse, or unmarked container using obstacle-aware A* pathfinding, pause briefly to pick up the loot within arm's reach, and move on to the next target.
- **Physical Chest-to-Chest Base Sorting (`F7`):** removed the instant-teleport sort button—companions now walk to each source/drop-off chest, take a batch into their carry buffer at close range, walk to each categorized destination chest, and place the items inside.
- **No-Teleport Combat Interruption:** if a fight breaks out while a companion is carrying items between chests, carried items stay in the companion's pack (or drop at their feet if full) instead of teleporting back across the base.

Requires third-party [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Safe for existing saves.

## Умные напарники 1.7.0 — реальный сбор лута и разноска по ящикам ногами

В версии **1.7.0** полностью убрана мгновенная «телепортация» предметов — теперь любую вещь напарники подбирают и переносят только вживую ногами:

- **Честный обход лута на земле, в трупах и диких ящиках:** по приказу собрать трофеи (и при авто-луте) напарники выстраивают маршрут, подходят к каждому предмету, трупу или ящику с обходом препятствий по A*, делают короткую паузу на подбор вплотную и идут к следующей точке.
- **Физическая разноска между ящиками базы (`F7`):** убрана читерская кнопка мгновенной сортировки — напарники подходят к ящику-источнику, забирают партию вещей в руки, идут к целевому ящику нужной категории и укладывают предметы на месте.
- **Отмена переноски в бою без телепортации:** если во время сортировки начался бой, переносимые вещи остаются в рюкзаке напарника (или сбрасываются у его ног при переполнении), а не телепортируются обратно через всю базу.

Требуется сторонний загрузчик [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Сброс сохранений не нужен.
