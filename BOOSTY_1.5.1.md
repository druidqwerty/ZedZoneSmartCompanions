## Smart Companions 1.5.1 — Experimental

This update adds guarded initialization for human NPCs when multiplayer loading encounters missing or invalid ranged-weapon data. The squad still brings tactical combat, base logistics, draggable controls and live chatter.

**Important:** this version passed an isolated startup check, but it has **not** been tested in a real two-player co-op world. Whether a joining player can see human NPCs is **unconfirmed**; this is not a verified fix. Please test with host and client and report what the client sees.

Requires [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). No save reset is intended.

## Умные напарники 1.5.1 — экспериментальная версия

Добавлена защита инициализации человеческих NPC, если при сетевой загрузке отсутствуют или повреждены данные дальнобойного оружия. Тактический бой, логистика базы, перетаскиваемый интерфейс и живые реплики остаются с вами.

**Важно:** версия прошла изолированную проверку запуска, но **не тестировалась в реальном кооперативном мире с двумя игроками**. Видимость NPC у подключившегося игрока **не подтверждена**; это не проверенное исправление. Проверьте вместе на хосте и клиенте и сообщите, что видит клиент.

Требуется [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Сброс сохранений не предполагается.
