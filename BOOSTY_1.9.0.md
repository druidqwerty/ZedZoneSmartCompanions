## Smart Companions 1.9.0 — Safer co-op orders

- **The host checks every order:** only a companion's owner can change its doctrine or ownership.
- **No tug-of-war:** if two players change the same companion at once, the first change wins and every screen shows the same state.
- **Quick clicks still land** in the right order.
- **Allies' companions are view-only** in F8, marked with the owner's name.
- **Mixed 1.8.x / 1.9.0 sessions keep working.** Update both players for full protection.

Single-player gameplay, physical looting and existing saves are unchanged. The host's rules passed a 13-case test in the real game; a real two-player session is still untested, so please report co-op issues in the Workshop discussions.

## Smart Companions 1.9.0 — Надёжные приказы в кооперативе

- **Каждый приказ проверяет хост:** менять доктрину или владельца может только владелец напарника.
- **Нет перетягивания:** если двое меняют одного напарника одновременно, побеждает первое изменение, у всех одинаковая картина.
- **Быстрые клики не теряются** и применяются по порядку.
- **Чужие напарники — только просмотр** в F8, с именем владельца.
- **Смешанные сессии 1.8.x / 1.9.0 работают.** Для полной защиты обновитесь оба.

Одиночная игра, физический лут и сохранения не изменились. Правила хоста прошли тест из 13 случаев в настоящей игре; настоящая сессия вдвоём пока не проверена — пишите о проблемах кооператива в обсуждениях Workshop.
